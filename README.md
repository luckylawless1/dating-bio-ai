## The bio

> I've already simulated our first date 12,000 times. In 11,999 of them you ghost me — let's beat the odds.

## How it works

`main.ts` (Node 22, stdlib only) writes the bio to `/output/entry.txt`.
The bio is a single line of 105 characters, inside the 180-character gate.

```sh
node main.ts
cat /output/entry.txt
```
